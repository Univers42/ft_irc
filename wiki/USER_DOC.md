# IRC Server Setup & QuickStart Guide

## prerequisites
- A compiled `ircserv` executable
- An IRC client installed (e.g., HexChat, Irssi, or netcat/nc for testing).

## Lauching the server
Run the server from our terminal by specifying a port and a network password:

```bash
./ircserv <port> <password>
```
- Example: `./ircserv 66667 mysecretpassword`
